## Introducción

En el mundo de la informática, las terminales son una de las herramientas más antiguas y fundamentales. Aunque hoy las asociamos con ventanas de comandos en sistemas modernos, su origen se remonta a máquinas mucho más primitivas.


## ¿Qué es una terminal?
Una terminal (o consola) es una interfaz de texto que permite a los usuarios interactuar con un sistema informático mediante comandos. A diferencia de las interfaces gráficas (GUI), las terminales funcionan con instrucciones escritas, lo que las hace rápidas, eficientes y esenciales para administradores de sistemas, desarrolladores y entusiastas de la informática.

Existen dos tipos principales:

- **Terminales físicas:** Dispositivos hardware dedicados (como los antiguos teletipos).

- **Terminales virtuales:** Emuladores de terminal (como Bash en Linux o PowerShell en Windows) que funcionan dentro de un entorno gráfico.

| -------------- | -------------------------------------------------------- | -------------------------------------------------- |
| 1960s          | Teletipos (TTY)                                          | Solo texto, impresión en papel                     |
| 1970s          | Terminales CRT (VT100)                                   | Pantallas electrónicas, teclados                   |
| 1980s          | Terminales gráficos (XTerm)                              | Soporte para múltiples ventanas                    |
| 1990s-2000s    | Emuladores modernos (GNOME Terminal, iTerm)              | Pestañas, colores, scripting                       |
| 2010s-Presente | Terminales hiperconectadas (Windows Terminal, Alacritty) | GPU-acceleración, plugins, integración con la nube |
