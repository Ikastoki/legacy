## ¿Qué es el diseño web?

El diseño web es el proceso de conceptualizar, planificar y crear el contenido visual, la estructura y la funcionalidad de un sitio web. Va más allá de simplemente hacer que una página se vea bonita; se centra en la experiencia del usuario (UX) y en la interfaz de usuario (UI) para asegurar que el sitio sea intuitivo, fácil de navegar y atractivo. El objetivo final es crear una experiencia digital que sea eficaz, accesible y responda a las necesidades de los usuarios.

## Historia y evolución del diseño web

El diseño web ha evolucionado drásticamente a lo largo de los años, adaptándose a los avances tecnológicos y las necesidades de los usuarios.

- Década de 1990 (Tablas y "pixel art"): Los primeros sitios web eran estáticos y se creaban principalmente con HTML. Los diseños se construían con tablas, lo que hacía que la maquetación fuera rígida y poco flexible. La estética era simple, con paletas de colores limitadas.

- Década de 2000 (CSS y Flash): Con la llegada de CSS (Cascading Style Sheets), se separó el contenido del estilo. Esto permitió diseños más complejos y dinámicos. En esta época, Flash se popularizó para crear animaciones y efectos, aunque tenía desventajas de rendimiento y accesibilidad.

- Década de 2010 (Diseño Responsivo y Mobile-First): El auge de los smartphones obligó a los diseñadores a crear sitios que se vieran bien en cualquier dispositivo. Nació el diseño responsivo, que permite que la web se adapte al tamaño de la pantalla. El enfoque Mobile-First (diseñar primero para móviles y luego para pantallas más grandes) se convirtió en una práctica estándar.

- Actualidad (Interfaces de usuario avanzadas): Hoy en día, el diseño web se centra en la accesibilidad, la optimización del rendimiento y la personalización. Herramientas como Flexbox y Grid facilitan la creación de diseños complejos y flexibles, mientras que el foco está en la creación de experiencias de usuario fluidas y atractivas.

## Principios de Diseño (CRAP)

Para crear un diseño visualmente atractivo y funcional, los diseñadores se basan en cuatro principios fundamentales, a menudo conocidos por sus siglas en inglés CRAP:

- **Contraste**: Destacar elementos importantes. Esto se logra usando diferencias de color, tamaño, forma o tipografía para guiar la atención del usuario.

- **Repetición**: Mantener la coherencia visual. Usar los mismos estilos, colores, tipografías y espaciados a lo largo del sitio para crear una apariencia unificada y profesional.

- **Alineación**: Organizar los elementos de manera intencionada. Todo en la página debe estar alineado con algo más, ya sea a la izquierda, a la derecha, al centro, etc. Esto crea una sensación de orden y limpieza.

- **Proximidad**: Agrupar elementos relacionados. Colocar elementos cercanos entre sí implica que tienen una relación lógica. Esto ayuda a los usuarios a escanear y entender la información más rápido.

Aunque son campos complementarios, es fundamental distinguirlos.
