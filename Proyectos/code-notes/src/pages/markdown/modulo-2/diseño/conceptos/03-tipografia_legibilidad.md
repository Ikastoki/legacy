## Tipografía en el Diseño Web

La tipografía es el arte y la técnica de organizar el tipo para hacer que el lenguaje escrito sea legible y atractivo. En diseño web, no solo se trata de elegir una fuente, sino de cómo esa fuente se aplica para comunicar el mensaje de manera efectiva.

## Tipos de Fuentes

Existen miles de fuentes, pero se suelen clasificar en dos categorías principales:

### Fuentes con Serifa (`serif`)

Tienen pequeños remates o adornos al final de los trazos de las letras (como la fuente Times New Roman).

- Características: Tradicionales, formales y elegantes. Suelen ser muy legibles en textos impresos largos, pero en pantallas pueden parecer menos claras.

- Uso: Ideales para encabezados en sitios web con un estilo más clásico.

### Fuentes sin Serifa (`sans-serif`)

No tienen estos adornos (como la fuente Arial).

- Características: Modernas, minimalistas y limpias. Se consideran más legibles en pantallas digitales, por lo que son la opción preferida para el cuerpo del texto en la web.

- Uso: Perfectas para títulos, cuerpos de texto, botones y cualquier elemento que necesite ser leído rápidamente en una pantalla.

Fuentes de Exhibición (`display`) y Manuscritas (`script`)
Se utilizan para fines decorativos y para captar la atención.

- Características: Muy estilizadas y con personalidad.

- Uso: Ideales para logotipos o títulos muy cortos, pero no para párrafos largos, ya que su legibilidad es baja.

## Legibilidad y accesibilidad

La legibilidad se refiere a la facilidad con la que el ojo humano puede distinguir las letras de una fuente y las palabras en un texto. Una buena tipografía debe ser accesible para todos los usuarios.

Para mejorar la legibilidad, es crucial prestar atención a las siguientes propiedades de CSS:

### Tamaño de la Fuente (`font-size`)

- Para el cuerpo del texto, un tamaño entre 16px y 18px es lo ideal.

- Asegúrate de que los encabezados tengan un tamaño mayor para establecer una jerarquía clara.

### Contraste de Color

- El texto debe tener un contraste suficiente con el color de fondo. Un texto claro sobre un fondo oscuro, o viceversa, es fundamental para que el texto sea legible.

- Puedes usar herramientas online para verificar que el contraste cumpla con los estándares de accesibilidad (como las WCAG).

### Espaciado de Línea (`line-height`)

También conocido como interlineado, es el espacio vertical entre las líneas de texto. Un `line-height` de 1.5 a 1.7 veces el tamaño de la fuente suele ser el más cómodo para la lectura.

### Longitud de Línea

Las líneas de texto no deben ser ni demasiado largas ni demasiado cortas. Una longitud óptima está entre 45 y 75 caracteres por línea.

> ✍️ Nota
> 
> Es buena práctica limitar el número de fuentes en un diseño a dos o tres como máximo. Usar demasiadas fuentes puede hacer que el sitio se vea desordenado y poco profesional.
